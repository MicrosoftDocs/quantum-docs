# Reference: Microsoft Quantum Development Kit extension for Visual Studio Code

The Microsoft Quantum Development Kit (QDK) uses the standard functionality of Visual Studio Code (VS Code), along with language-specific features when you work with `.qs` or `.qasm` files. This reference guide describes the main QDK commands in the VS Code Command Palette, along with other features and links to more content. For general VS Code guidance, see the [VS Code documentation](https://code.visualstudio.com/docs).

To find QDK commands, select **View > Command Palette** and enter **QDK:** or **Microsoft Quantum:**. Some commands appear only when a supported file or view is active.

> [!TIP]
> Create custom keyboard shortcuts for VS Code commands by using **Keyboard Shortcuts** or by pressing **Ctrl + K + S**. For more information, see [Key Bindings for VS Code](https://code.visualstudio.com/docs/getstarted/keybindings).

## Commands

Many QDK commands for writing and running Q# and OpenQASM programs are only available when a `.qs`, `.qasm`, or `.qsc` file is active. Other commands are always available.

## Panel views

Q# and OpenQASM programs use the following views in the VS Code panel:

| View              | Action                           |
|-------------------|----------------------------------|
| **Debug console** | Shows run output or debug output |
| **Problems**      | Shows precompile error checks    |

## Edit Q# and OpenQASM code

Most common code editing features in VS Code are also available for Q# and OpenQASM programs:

- Precompile error checks
- Go-to definition
- References
- Function signatures
- Parameter information
- Completion suggestions, including context-aware, namespace member, and type member completions
- Linting. For Q# files, configure linting per project in the manifest file. For more information, see [Working with Q# projects](xref:microsoft.quantum.qsharp-projects#manifest-file-examples).

For more information, see [IntelliSense](https://code.visualstudio.com/docs/editor/intellisense) in the VS Code documentation.

## Common tasks

The following tables list commands for common tasks in the QDK extension.

### Work with Q# files and projects

| Task                 | Action                                                                                                                                                                                         | Notes                                                                                                                                                 |
|----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| Create a new Q# file | Select **File > New file > Text file**. Save the file with a `.qs` extension.                                                                                                                  | If you set `Files: Default Language = qsharp`, new files automatically default to Q# formatting.                                                      |
| Create a Q# project  | From an open folder in File Explorer, select **QDK: Create Q# project** from the Command Palette. Or, open the shortcut menu for the folder in File Explorer and select **Create Q# project**. | For more information about Q# projects, see [Working with Q# projects](xref:microsoft.quantum.qsharp-projects).                                       |
| Create a sample file | In a blank `.qs` or `.qasm` file, enter *samples*, and then select a sample program from the list.                                                                                             | You can also select **QDK: Open QDK playground** in the Command Palette to open an online folder of Q# and OpenQASM sample programs in File Explorer. |
